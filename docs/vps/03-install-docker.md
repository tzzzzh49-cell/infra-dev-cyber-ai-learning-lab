# 03 - Installation Docker

Objectif : préparer Docker Engine et le plugin Docker Compose sur le VPS.

Points de contrôle :

- installer Docker depuis une source officielle adaptée à la distribution ;
- vérifier `docker --version` ;
- vérifier `docker compose version` ;
- limiter l'accès au groupe `docker` aux utilisateurs de confiance ;
- documenter toute étape manuelle hors dépôt.

Aucun secret n'est requis pour cette étape.
