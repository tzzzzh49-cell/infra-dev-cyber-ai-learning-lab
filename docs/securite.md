# Sécurité

La documentation de sécurité active du projet Hermes + OpenClaw Gateway se trouve
dans [`docs/SECURITY.md`](SECURITY.md).

Ce fichier est conservé pour compatibilité avec les anciens liens du lab
réseau/FastAPI. Les règles actuelles interdisent tout secret réel dans Git : clé
API, token Telegram, session WhatsApp, fichier `.env`, clé SSH privée,
sauvegarde, log privé ou capture brute.
