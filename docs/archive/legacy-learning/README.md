# Anciens supports d'apprentissage

Ce répertoire conserve, sans modification de contenu, les documents d'apprentissage antérieurs à l'édition lab du guide.

Ils sont historiques et non canoniques : ils ne doivent servir ni de source d'apprentissage, ni de critère d'évaluation, ni de preuve créditable. La source d'apprentissage active est déclarée dans `curriculum/active.json`.

Fichiers archivés :

- `ROADMAP.md` ;
- `journal-apprentissage.md` ;
- `linux-ssh.md`.
