# Architecture

La documentation d'architecture active du projet Hermes + OpenClaw Gateway se
trouve dans [`docs/ARCHITECTURE.md`](ARCHITECTURE.md).

Ce fichier est conservé pour compatibilité avec les anciens liens du lab

historiques du dépôt (`app/`, `ansible/`, `compose.yaml`, `openclaw/`, `outputs/`)
restent présents et devront être migrés ou archivés dans une PR dédiée.
